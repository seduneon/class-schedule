# Tiny example (golden test)

Three professors (A, B, C), four lecture sections (MATH 161 ×2, MATH 351, MATH 361),
two rooms, four time patterns. Small enough to solve by hand; the expected optimal
objective values per level are derived in `tests/integration/test_golden_tiny.py`.
MATH 351 and MATH 361 form the auto-generated `level_300` conflict group (B5).
